# 🚀 TaskMaster CLI

**TaskMaster CLI**, terminal üzerinden günlük görevlerinizi yönetmenizi sağlayan, Python ile yazılmış modern ve estetik bir araçtır. `Typer` ve `Rich` kütüphaneleri kullanılarak geliştirilmiştir.

## 📸 Özellikler

* ✅ **Kolay Kullanım:** Basit komutlarla görev ekleme, silme ve güncelleme.
* 🎨 **Zengin Arayüz:** Renkli tablolar ve emojilerle görselleştirilmiş çıktı.
* 💾 **Veri Kalıcılığı:** Görevleriniz yerel bir JSON dosyasında saklanır, kaybolmaz.
* 🏷️ **Kategorilendirme:** Görevlerinizi kategorilere ayırabilirsiniz.
